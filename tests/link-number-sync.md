# LINK No.と調整量入力の連動

ピッチリンク画面の調整量「1：」でNo.1〜3を選ぶと、左下のLINK No.ボタンと同じ候補選択処理を実行します。「4：」のUP/DOWN、共有調整量、予測ドット、ガイド線がそのNo.の表示と揃います。タップ・ホイール選択中に即時反映し、「決定」で維持、「キャンセル」または背景タップで元の入力・No.・ガイド・予測へ戻します。左下のNo.ボタンの順送りも同じ処理を使います。

既存の候補順位、方向の評価、距離・座標の計算、学習、実測履歴、確定ロック、2段階参考予測は維持しています。学習済み候補がないNo.には別のNo.のガイド・予測を流用しません。TABのNo.入力は従来の動作です。

## 検証

`link-number-sync.html?isolated=1` は、左下ボタンを実際に切り替えて取得した表示を期待値にし、「1：」の各No.を選んだ表示と比較します。手動・学習待ち・学習済み、ガイドON/OFF、即時タップ・ホイール、決定・キャンセル・背景タップ、調整量変更、画面往復、順位・学習・実測・2段階参考予測の不変性、確定ロックを320／375／390／430pxで検証します。794項目PASSです。

変更前のアプリのコピーでは、同じテストがNo.2の選択不一致を検出しました。旧仕様でLINKのNo.入力変更時にガイド・予測が隠れることを期待していた既存テストは、今回の連動仕様へ更新しています。未入力予測の保護と候補欠測の検証も維持しています。
