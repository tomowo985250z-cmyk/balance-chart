# 実調整学習の隔離比較試験

本番コードを読み取ってメモリ内だけで比較します。アプリの保存領域を開かず、`localStorage`・`sessionStorage`・端末のバックアップを書き換えません。本番からこのフォルダーを読み込みません。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./tests/learning-study/run.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./tests/learning-study/run-image-analysis.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./tests/run-browser-tests.ps1 -Tests all
```

Windowsのインストール済みEdgeを専用一時プロファイルで起動します。生成物の標準保存先は `output/learning-analysis/`。上の2つの分析コマンドは `-OutputDirectory` で出力先を指定できます。システムの実行ポリシーは変更しません。比較試験は数分かかります。

`analysis-results.json` は既存31件の距離参照の内訳、初期値経路の再現、固定した6方式の比較を保存します。7条件×4 seedの合成履歴を各120操作生成し、先頭72操作を学習専用、残り48操作を1操作先の逐次検証に使います。各操作を予測してから、その実測を確認・学習します。最終48操作の最初から最後まで未来の測定を参照しません。

比較対象は現行方式、更新率0.20／0.35／0.90への変更案、角度と対数単位距離を別々に推定する頑健な親・詳細混合案、十分な反復がある場合だけ学習データ内の逐次検証で比例式より20%以上よいべき乗式を許す案です。0.60以外の現行方式の候補は、読み取ったソースの `RATE` 定数だけを独立したメモリ内コピーで変更します。距離更新上限は維持するので、更新率がそのまま距離の重みになるとは限りません。

頑健案は0.35の指数重み、親の直近18件・詳細の直近12件、中央値とMADに基づく重み制限を使います。角度は直近残差を基準に±180度へ折り返し、親とNo./方向別の推定を混ぜます。距離は量で正規化して対数空間で推定します。べき乗案は詳細8件以上、2量以上・各3件以上・量の幅2倍以上、過去側だけの内側検証3件以上を条件にし、指数を0.5〜1.5へ制限します。これらの閾値は試験の固定値で、実測から妥当性を確認した値ではありません。

誤差は角度MAE（度）、移動距離MAE（IPS）、終点XY誤差MAE/RMSE/P90（IPS）、中心からのIPS値の絶対誤差を区別します。欠測は0点にせず、方式ごとの予測件数と現行・候補の共通対象件数を保存します。現在の履歴確認UIがTABのHOVを学習しない点もそのまま再現しています。静的な実測priorは合成履歴の評価へ混ぜません。

最適No.・方向の照合は、合成データで定義した全候補の真値に対して既存の順位方式をそのまま適用した結果との一致です。LINKは既存の `BalanceLinkRanking`、TABは巡航のみの既存の改善候補・0.15圏内・距離の順序を使います。実測では未実施の候補の真値が分からないため、実機のNo.選択正解率には換算できません。

2段階は既存 `BalanceTwoAdjustment.search` の全1,944組を、3つの合成条件・3方式で比較します。TAB HOVはどの方式も同じ公称fallbackで固定しており、新しいTAB HOV学習を追加した試験ではありません。実際の2段階参考予測との接続・確定ロックは既存回帰テストでも保護します。

`image-analysis-results.json` は確認済み画像6結果の前後実測ベクトル、7件のIPS値の残差、同じ履歴だけの逐次再生を保存します。予測の時計角・XYがないため、画像の予測角度誤差・移動距離誤差・終点XY誤差は `null` のままです。表示された小数2桁のIPSと分単位の時計値から導出した概算であり、測定精度を推定したものではありません。
