# LINK新順位 本番実装の回帰結果

2026-10-11、専用の一時Edgeプロファイルで実行。push未実施。

本番は新方式のみ。既存のNo.1〜3、調整量フォーム、ガイド表示、学習・予測エンジン、保存形式を維持する。旧方式はテスト比較用スクリプトに限定し、本番UIへ切替を追加しない。

両方の予測終点が厳密に0.2 IPS以下なら最優先し、最大中心距離→合計中心距離。該当なしならHOV圏内到達・維持を優先する。HOV圏内候補もなければ方向区分「両方中心向き → HOVのみ中心向き → 巡航のみ中心向き → 両方中心向きでない」を優先し、同方向区分内だけ予測終点で評価する折衷方式を本番へ反映した。巡航未測定ならHOVのみ。0.18は参考目標だけで順位に影響しない。合格境界にepsilonや表示丸めを使用しない（合格候補の距離順位の同値比較のみ1e-9 IPS）。

最新の本番反映・回帰結果は [link-ranking-hybrid-production-results.md](link-ranking-hybrid-production-results.md) を参照。以下の15群11,369チェックとNo.3 DOWNの詳細調査は折衷方式反映前の記録。現在は方向区分内でHOV終点を厳密に判定し、同じHOV終点だけ巡航終点を比較する。改善後のNo.3はUPとなる。

評価終点は表示中の共有調整量と既存の `learning.predict`・`BalanceDistancePrior.resolve`・ガイド方向から算出する。調整量の確定時に再順位付けするが、No・方向の個別入力は上書きしない。仮選択では順位を変えない。確定済み予測は再描画で書き換えない。

参考推定・欠測は既存メッセージ欄に「予測不確実」、学習予測を含めて「予測の実測精度は未検証」と明示する。学習・予測・保存エンジンのファイルは変更していない。

0.2の直前・一致・直後（隣接する浮動小数点数）、0.2000000005の反例、0.18境界での順位不変、外向きの合格終点、行き過ぎ、巡航欠測と予測欠測の区別、学習不足、HOV維持、No別の予測表示一致を検証した。採用した優先順位を前提としてテストを更新し、予測値・学習データを変えずに比較した。

同量・同終点の合成400ケース（seed=91571）の両予測0.2以内は旧181/400、新270/400。HOV合格386/400。旧が両方合格している場合の最大距離悪化0件、最大同値時の合計悪化0件。HOV優先による最大距離増加52件、最大距離を優先した合計増加11件は既存分析どおり。0.18は順位に影響しない。合成データの結果であり、実測達成率・予測誤差・境界誤判定率ではない。

未完了・既存不一致は通過数に含めない:

- `learning.html` は74チェック後、`tests/learning.test.js:160` のCruise TAB距離参考値の由来に対する期待値で失敗。本番アプリを読み込む前の段階。変更前のHEADを一時フォルダーへ複製しても同一箇所・同一内容で失敗した。距離推定の既存TAB単調補正とテスト期待値の不整合であり、この実装ではエンジンや当該テストを変更していない。全学習テストの完走を確認したとはしない。
- `initial-position.html` はheadless実行でダイアログclose待ちのまま終了した（今回28チェック、変更前HEADでも9チェックで同様に未完了）。本番の初期位置機能に新規不具合があるとは断定できないが、この自動テストの完走は未確認。

実測精度・正式整備基準との整合を確認した結果ではない。実測時系列による追加検証は未実施。
