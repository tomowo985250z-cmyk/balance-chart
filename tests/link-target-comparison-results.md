# 予測目標0.18／合格0.2の試験比較

予測目標を暫定0.18 IPSへ変更。合格判定はHOV・巡航とも0.2 IPS以下を維持し、目標と合格を分離した。同一共有調整量・同一予測終点で比較する。学習・predict・距離推定・確定予測は変更しない。

## 順位規則

1. 巡航測定済みなら、両終点が厳密に0.2以下の候補を最優先。
2. その中で両終点が厳密に0.18以下の候補があれば優先し、最大中心距離→合計中心距離で比較。
3. 両方0.2以下にできなければ、HOV 0.2以下を優先し、その中で最大→合計。HOVだけ0.18にできることを理由に巡航の良い候補を後回しにしない。
4. HOV 0.2以下の候補もなければHOV改善量→最大→合計。
5. 巡航未測定ならHOV 0.2以下を優先、その中で0.18を目指し、HOV中心距離で比較。

両方0.19にできる候補は、HOVだけ0.17／巡航0.4になる候補より必ず優先する。HOV0.19／巡航0.21とHOV0.17／巡航0.4のように両合格候補がない場合でも、HOVの合格を維持しながら最大距離の小さい前者を選ぶ。

0.18と0.2の境界にはepsilonや表示丸めを使わない。保持している数値を直接`<=`で比較する。1e-9 IPSは境界を拡張せず、同じ候補群内の距離順位の同値比較だけに使う。境界付近では表示値も元の精度で示す。この厳密判定は入力・予測の実機精度を保証しない。
