## 評価手順

同じ指定量でNo.1～3それぞれのUP/DOWNを比較し、各No.から1方向を選択する。その3候補だけを順位付けし、第2段階で方向を選び直さない。全9量を個別に比較し、量の自動変更や異なる量同士の比較はしない。

第1段階（`improvement-aware`）の優先順：

1. HOV・巡航の両予測終点が厳密に0.2以内。
2. HOVの既知終点が0.2以内。HOV終点欠測で幾何学的に維持可能な候補は別区分、その後は維持予測なしの診断候補。
3. 巡航の証拠を「既知終点が現在より改善 → 終点欠測だが中心向きで改善の幾何学的可能性あり → 既知の同距離 → 既知の悪化 → 改善方向の根拠なし」に分ける。
4. 同じ証拠区分の既知候補は終点距離を比較し、行き過ぎを評価する。幾何学的可能性だけの候補は0.2への到達可能性・方向角を比較する。

圏内候補同士のHOV中心距離は順位に使わない。欠測の中心向き候補は既知の悪化より先に残せるが、予測改善・0.2達成とは扱わない。「改善方向の根拠なし」も悪化確定とは区別する。この並びは試験上の証拠の優先順で、達成確率ではない。

第2段階は前回の「既知終点優先」を使用する。両達成予測 → HOV維持 → 巡航中心向き → 同方向区分で既知終点 → 幾何評価の順。同じ基準を両段階に使う `same-rule` も対照試験した。

両達成予測・利用可能なHOV維持予測の喪失は、最終1位でも各No.の方向選択でも0件。両達成予測421件は維持したが、追加達成予測は0件。

最終1位の欠測は全体で342件減る一方、選ばれた3方向すべてでは342件増える。集計単位が異なるため、欠測全般が改善したとは言えない。改善証拠を区別した方向選択では、既知の行き過ぎを同じNo.の反対方向と比べることで、同一基準対照案の既知終点悪化243件を解消した。これは下位候補も含む方向選択の結果であり、最終1位の追加改善件数ではない。

## HOV維持予測がある条件に限定

全体にはHOV維持予測候補のない診断条件1,464件が含まれる。実行候補としての検討に近い、少なくとも1候補にHOV維持予測がある1,128条件の集計は次のとおり。

| 指標 | 既存方式 | 2段階・改善証拠を区別 |
|---|---:|---:|
| 最終1位の両達成予測 | 421 | 421 |
| 最終1位の変更条件 | — | 97 |
| 3候補の順序・方向の変更条件 | — | 734 |
| 最終1位の巡航終点欠測 | 72 | 144 |
| 選ばれた3方向すべての巡航終点欠測 | 864 | 1,206 |
| 最終1位の既知巡航終点悪化（双方既知984条件） | — | 2 |
| 同じNo.の既知巡航終点悪化（双方既知2,070比較） | — | 0 |

この区分の「同じNo.」比較には、そのNo.自身にHOV維持予測がない方向も含まれる。各No.に維持予測がある場合は必ず保護する。全体欠測減少の多くは診断条件の414件の欠測解消に由来し、HOV維持候補がある条件では新規欠測72件が残る。

## 前回案から変わった点と限界

同一基準を2段階に分けただけの対照案は、前回の6候補直接比較と全2,592条件で3候補の順序・方向まで一致した。分割だけでは結果は変わらない。

改善証拠を区別する第1段階を使うと、前回案から477条件で下位候補の方向・順序が変わる（各No.の方向変更477件、No.の並び変更381条件）。HOV維持候補のある区分では41条件・41方向・No.の並び17条件。ただし**最終1位は前回案と全条件で同じ**。巡航欠測144件・終点悪化2件の追加削減はなく、最終1位の最大終点距離悪化61件・合計終点距離悪化95件も残る。維持候補のある区分では各25件・14件。

方向選択の改善例：HOV中心、巡航0.19・時計角0°、1/4 flat。前回案はNo.2 DOWN（HOV 0.161504、巡航0.301947・中心向きだが行き過ぎ）。今回の第1段階はNo.2 UP（HOV 0.078099、巡航0.278676・外向き）を選び、どちらも悪化予測の中で小さい終点を残す。第2段階の並びは前回「1 UP → 2 DOWN → 3 DOWN」から「1 UP → 3 DOWN → 2 UP」。No.3 DOWNは巡航欠測で幾何学的可能性のみ。最終1位No.1 UPは変わらない。

残る最終1位の悪化2件は、HOV 0.19または0.2・時計角120°、巡航0.19・時計角0°、1/2 flat。既存No.3 UPの巡航0.526078に対しNo.2 DOWNは0.531278（約0.005200悪化）。第2段階で中心向き優先を保つため残る。
